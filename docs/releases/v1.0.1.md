# Dexterpreter v1.0.1


## Release Note

`v1.0.1` is the first clean Dexterpreter release tag. `v1.0.0` already existed before the Dexterpreter release finalization and pointed to older release content, so this release uses `v1.0.1` instead of rewriting the old tag.

## Summary

Dexterpreter 1.0.1 prepares the app as a local/offline audio transcription and
translation tool.

Short description:

> Offline audio transcription and translation. No cloud. No nonsense.

Current supported pipeline:

1. Spanish audio.
2. Spanish transcript.
3. English translation.

The app is language-expandable, but this release does not claim additional
language support.

## Install Notes

This APK is unsigned and intended for testing/review unless locally signed
before distribution.

On Android, sideloading may require allowing installs from the browser or file
manager used to open the APK.

## First-Run Model Note

The first transcription requires internet access once so Dexterpreter can cache
the selected Whisper model and the Spanish-to-English translation model. After
the model cache is present, transcription and translation run locally/offline.

Clearing app storage or selecting a model tier that has not yet been cached can
require another one-time model download.

## Current Language Support

- Spanish audio transcription.
- Editable Spanish transcript.
- English translation from the Spanish transcript.

Additional language paths are not complete in this release.

## Validation Performed

- `npm install`: completed.
- `npm run build`: completed.
- `npm run test`: passed, 18 test files and 118 tests.
- `npm run eval:gate`: ran.
- `npx cap sync android`: completed.
- `./gradlew clean assembleRelease`: completed and produced an unsigned release APK.

## Validation Not Performed

- Real accuracy validation is incomplete because the evaluation gate only had a
  demo fixture, and that fixture is excluded from aggregate scoring.
- Signed release validation was not performed because signing credentials were
  not available in the environment.

## Signing Status

This release artifact is unsigned.

Release signing is configured to use local environment variables only:

- `DEXTERPRETER_RELEASE_STORE_FILE`
- `DEXTERPRETER_RELEASE_STORE_PASSWORD`
- `DEXTERPRETER_RELEASE_KEY_ALIAS`
- `DEXTERPRETER_RELEASE_KEY_PASSWORD`

Keystores, passwords, aliases, and signing credentials must not be committed.

## Known Limitations

- Unsigned APK is not a final signed public release package.
- Evaluation coverage is currently demo-only and does not prove production
  transcription accuracy.
- Version 1.0.1 supports Spanish-to-English only.

## Privacy Statement

Dexterpreter does not add a backend, cloud application programming interface,
telemetry, analytics, tracking, or account system.

Audio, transcripts, translations, and saved projects stay on-device.

No personal identifying information is included in these release notes.
